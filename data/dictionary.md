# Column dictionary

- gateway / hq_country / regions: identity & coverage
- domestic_card_fee / international_fee: indicative published rates (see official_fees_url)
- payout_speed / subscriptions_support / hosted_checkout: capability flags
- best_for: recommended use case
- status_stamp: compile date of the indicative figures
- dom_pct / dom_fixed / intl_pct: numeric fee model parsed for the calculator (blank = quote-based)
